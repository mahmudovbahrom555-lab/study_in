# MaMu Learn — фирменный стиль

Правила для всех, кто делает экраны, сторы, презентации и печать. Файлы лежат рядом, в `brand/`.

## 1. Название

Пишем **MaMu Learn**: две заглавные M, между словами пробел.
Не пишем: «Mamu Learn», «MAMU LEARN», «MaMuLearn», «Мама Learn».

## 2. Знак «Росток»

Два листа растут из одной точки:
- **рост:** обучение — это движение вверх;
- **два листа — две дочери владельца**, Марджона и Мубина: отсюда «MaMu»;
- **галочка:** вместе листья читаются как «✓» — «сделано, принято».

Знак собран из двух фигур на сетке 64×64 с шагом 8. Он проверен на размерах 16–512 px, при размытии, в ч/б, в инверсии и среди иконок других приложений.

## 3. Файлы

| Файл | Где использовать |
|---|---|
| `logo/logo.svg` | Основной логотип: знак + надпись, на светлом фоне |
| `logo/logo-on-dark.svg` | Основной логотип на тёмном фоне |
| `logo/logo-black.svg`, `logo/logo-white.svg` | Одноцветная печать, гравировка, фото-фон |
| `logo/symbol.svg` | Только знак: аватары, favicon, места, где мало места |
| `logo/symbol-black.svg`, `logo/symbol-white.svg` | Знак в одном цвете |
| `logo/wordmark*.svg` | Только надпись, когда знак уже стоит рядом (например, под иконкой) |
| `app-icon/app-icon.svg` / `.png` | Иконка iOS, сторов и веба (1024×1024, без прозрачности) |
| `app-icon/app-icon-foreground.svg` / `.png` | Передний слой адаптивной иконки Android (знак на прозрачном) |

Надпись в SVG переведена в кривые, поэтому шрифт для открытия файлов не нужен.

## 4. Построение

- Основной логотип: высота знака ≈ 1,4 высоты прописной «M»; листья растут от базовой линии текста; зазор между знаком и надписью ≈ 0,4 высоты «M».
- **Свободное поле** вокруг логотипа — не меньше высоты прописной «M». Вокруг одного знака — не меньше ¼ его высоты.
- **Минимальный размер:** знак — 16 px; основной логотип — 24 px в высоту на экране и 8 мм в печати. Если меньше, ставим только знак.

## 5. Цвета

| Роль | HEX | Где |
|---|---|---|
| Фирменный синий | `#2563EB` | Знак, «Learn», фон иконки, главные кнопки |
| Тёмный синий | `#1E40AF` | Нажатое состояние |
| Светлый синий | `#60A5FA` | Знак и «Learn» на тёмном фоне |
| Текст | `#111827` | «MaMu» на светлом фоне, основной текст |
| Фон | `#F7F9FC` | Фон экранов |

Цвета совпадают с `flutter_app/lib/core/theme/colors.dart`. Контраст `#2563EB` на белом — 5,2:1: проходит WCAG AA для текста любого размера.

## 6. Шрифт

**Golos Text** (Google Fonts, лицензия OFL). Шрифт сделан для кириллицы и правильно рисует узбекскую кириллицу (Қ, Ў, Ҳ, Ғ) и латиницу с O‘/G‘.
- В логотипе: «MaMu» — Bold 700, «Learn» — SemiBold 600, трекинг −1%.
- В интерфейсе (когда подключим): Regular 400 и Medium 500 для текста, SemiBold 600 для заголовков.

## 7. Нельзя

- поворачивать, растягивать и отражать знак;
- менять пропорции листьев и их расположение;
- красить листья в разные цвета, добавлять градиент, тень или обводку;
- ставить логотип на пёстрое фото без подложки;
- менять шрифт надписи или перестраивать её;
- скруглять углы иконки приложения самим: iOS и Android накладывают маску сами.

## 8. Иконка приложения

- **iOS / сторы / веб:** белый знак (~60% ширины) на сплошном `#2563EB`, квадрат без скруглений и без прозрачности.
- **Android:** адаптивная иконка. Фон `#2563EB` и передний слой со знаком: знак занимает ~48 из 108 dp и целиком помещается в безопасную зону 66 dp при любой маске (круг, сквиркл, капля). Тот же слой служит монохромной иконкой для тематических иконок Android 13+.

После изменения исходников в `brand/app-icon/` все размеры пересобираются командой:

```
cd flutter_app
dart run flutter_launcher_icons
```

Известная ошибка генератора: он меняет `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS` в `ios/Runner.xcodeproj/project.pbxproj` на `AppIcon`. Это изменение откатываем: `git checkout -- ios/Runner.xcodeproj/project.pbxproj`.

## 9. Иконки интерфейса

Используем библиотеку **[Lucide](https://lucide.dev)** (лицензия ISC). Свои иконки не рисуем: смешение стилей сразу заметно.

- Сетка 24×24, линия 2 px, скруглённые концы и углы. Одна иконка — одно значение во всём приложении.
- Зона нажатия — не меньше **48×48 dp** (Android) и **44×44 pt** (iOS), даже если сама иконка 24.
- **Состояние не передаём только цветом:** «✓ Присутствовал / × Отсутствовал» — иконка плюс текст.
- У каждой кнопки-иконки есть подпись для экранного диктора (`tooltip` / `Semantics`).
