# План релиза MaMu Learn в Google Play

Основа сверки — 13 экранов HTML-макета и существующие Flutter-клиент и Go API.
Наличие экрана в исходниках ещё требует проверки на устройстве.

## 1. Подготовить воспроизводимую сборку

- [x] Согласовать версии Flutter и Go в CI с требованиями проекта.
- [x] Настроить Android API 36 и подпись релиза ключом загрузки.
- [x] Прогнать `go test ./...` и собрать сервер.
- [x] Прогнать тесты Flutter.
- [x] Исправить замечания анализа Flutter и пройти локальную проверку форматирования по команде CI.
- [x] Проверить доступ к отчёту ученика, границы месячного расчёта и обязательные настройки API для Android-релиза.
- [ ] Собрать и проверить подписанный AAB.
- [ ] Проверить Android 16 и поддерживаемые устройства, включая режим 16 КБ страниц памяти.

### Проверка на Android

1. Установить Android SDK Platform 36, Platform-Tools и NDK
   `28.2.13676358` (версия Flutter 3.38.9). Подключить устройство через
   USB-отладку или запустить эмулятор и проверить, что оно видно в `adb devices`.
2. Запустить отладочную сборку с адресом тестового API. Проверить первый запуск,
   вход и сценарии трёх ролей из раздела ниже. Для эмулятора и локального
   сервера использовать `http://10.0.2.2:8080/api/v1`.
3. Собрать подписанный AAB по [инструкции](../flutter_app/README.md).
   Проверить подпись командой `jarsigner -verify build/app/outputs/bundle/release/app-release.aab`.
   Сверить сертификат подписанта с сертификатом ключа загрузки в Play Console.
4. Проверить, что `bundletool validate` принимает AAB, а
   `bundletool dump config` показывает `PAGE_ALIGNMENT_16K`. Проверить запуск
   на Android с размером страницы 16 КБ (`adb shell getconf PAGE_SIZE` должно
   вернуть `16384`).

## 2. Проверить сценарии из макета

Первый исправленный сценарий — посещаемость. При смене даты старые отметки
скрываются, запоздавшие ответы игнорируются, а переход на другой день
доступен после завершения записи. Добавлены три теста на эти случаи.

| Роль | Проверка перед релизом |
| --- | --- |
| Репетитор | Войти, открыть список классов и класс, создать задание, отметить посещаемость, проверить работу и выставить оценку. |
| Ученик | Вступить в класс, открыть задание, отправить работу с вложением и увидеть оценку. |
| Родитель | Привязать ребёнка и открыть его успеваемость, посещаемость и уведомления. |
| Оплаты | По макету репетитор выставляет счёт за занятия и отправляет напоминание. Родитель оплачивает счёт, деньги поступают репетитору, чек появляется в приложении. До подключения выбрать провайдера и проверить правила Google Play для этой модели. Затем проверить подтверждение оплаты, повторные уведомления провайдера и отказ платежа. |
| AI-отчёт | По макету родитель получает недельный отчёт об успехах, пробелах и домашних упражнениях. Репетитор проверяет и может редактировать черновик до отправки. Сверить с имеющимися отчётами и проверить доступ к данным ребёнка, пустые данные и ошибки API. |

Повторить сценарии с аккаунтом другой роли и чужим классом, чтобы проверить
серверные ограничения доступа. Проверить ошибки сети, перезапуск и повторную
отправку работы. Сравнить экраны с макетом на Android.

## 3. Подготовить сервер и материалы магазина

- Развернуть API и миграции, проверить HTTPS, SMS, загрузку файлов, резервные
  копии и восстановление. Прогнать сценарии на тестовом окружении.
- Опубликовать политику и страницу удаления аккаунта на `mamu.education`.
  Проверить удаление из приложения и через сайт.
- Подготовить описание, скриншоты, возрастную аудиторию, рейтинг, доступ для
  проверки и декларацию Data safety по фактической обработке данных.

## 4. Выпустить через Play Console

- Загрузить подписанный AAB во внутренний тест. Установить приложение из Play
  и проверить вход и сценарии трёх ролей.
- Для личного аккаунта, созданного после 13 ноября 2023 года, провести
  закрытый тест с минимум 12 участниками, подключёнными непрерывно 14 дней,
  затем запросить доступ к Production.
- Отправить релиз на проверку и после публикации следить за сбоями и ошибками входа.

[Требования к целевому API](https://support.google.com/googleplay/android-developer/answer/11926878)
· [Требования к тестированию](https://support.google.com/googleplay/android-developer/answer/14151465)
