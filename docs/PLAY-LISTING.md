## Data safety (по факту)

Собирается (всё — для работы приложения и управления аккаунтом; не передаётся
третьим лицам; шифруется при передаче; можно удалить):

| Категория Play | Что именно | Обязательно? |
|---|---|---|
| Personal info → Name | имя | да |
| Personal info → Email address | email из Google-аккаунта | нет (только при входе через Google) |
| Personal info → Phone number | номер телефона | нет (только при входе по телефону) |
| Personal info → User IDs | идентификатор Google-аккаунта | нет |
| Photos and videos → Photos | фото в работах и заданиях | нет |
| Files and docs | PDF, Word в работах и заданиях | нет |
| Messages → Other in-app messages | чат и лента группы | нет |
| App activity → Other user-generated content | задания, ответы, оценки, посещаемость | нет |

Не собирается: местоположение, контакты, рекламный ID, финансовые данные,
здоровье, история браузера.

**[проверить]** в анкете: считать ли IP-адрес в журналах сервера
(хранится для работы и безопасности) — по правилам Play он может относиться к
«приблизительному местоположению».

## Перед подачей

1. Подключить SMS (Eskiz): вход через Google не может быть единственным —
   политика для семей требует, чтобы он был необязательным.
2. Загрузить AAB (workflow «Play Release») в закрытое тестирование.
3. Взять в Play Console SHA-1 ключа подписи приложения (Setup → App signing)
   и добавить его как ещё один Android-клиент в Google Cloud (проект MaMuLearn) —
   иначе вход через Google в версии из Play не работает.
4. 12+ тестировщиков, 14 дней подряд, затем запрос доступа к Production.
